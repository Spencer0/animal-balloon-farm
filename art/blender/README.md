# Blender asset pipeline

This folder contains deterministic Blender authoring scripts for Animal Balloon Farm. Keep modeling, rig/animation, export, and a review render in source control as an editable source plus generated outputs.

This file covers the Blender side only. For the end-to-end path — including the TypeScript registration points, garden placement, and the checklist for adding a new species — see [`../../ANIMAL_PIPELINE.md`](../../ANIMAL_PIPELINE.md).

## Balloon Pig: source, render, GLB

- Authoring script: [`balloon_pig.py`](balloon_pig.py)
- Editable Blender project: `../../public/assets/animals/balloon-pig.blend`
- Art-review portrait: `../../public/assets/animals/balloon-pig-review.png`
- Three.js runtime model: `../../public/assets/animals/balloon-pig.glb`
- Reusable operating skill: [`../../skills/blender-asset-pipeline/SKILL.md`](../../skills/blender-asset-pipeline/SKILL.md)

Run from the project root in PowerShell:

```powershell
blender --background --factory-startup --python art/blender/balloon_pig.py
```

This is a **regeneration** command: it creates/clears a temporary Blender scene and overwrites those three named outputs. Inspect shared changes and preserve any output edits first. It renders a still, saves the editable scene, and exports only the named pig rig as GLB with `WALK` and `IDLE` NLA animation tracks. The GLB uses a +X local forward direction; Blender Z-up is converted by glTF into Three.js Y-up.

Open `balloon-pig-review.png` to review the high-quality portrait, `balloon-pig.blend` to inspect source geometry, rig pivots, materials, camera and lights, and the game's browser preview to review the GLB at garden scale.

## Sheep, Cow, Chicken, Duck and Goose: sources, renders, GLBs

- Authoring script: [`balloon_friends.py`](balloon_friends.py)
- Sheep source / portrait / runtime GLB: `../../public/assets/animals/balloon-sheep.blend`, `balloon-sheep-review.png`, `balloon-sheep.glb` (approved; not regenerated by default)
- Cow source / portrait / runtime GLB: `../../public/assets/animals/balloon-cow.blend`, `balloon-cow-review.png`, `balloon-cow.glb`
- Chicken source / portrait / runtime GLB: `../../public/assets/animals/balloon-chicken.blend`, `balloon-chicken-review.png`, `balloon-chicken.glb`
- Duck source / portrait / runtime GLB: `../../public/assets/animals/balloon-duck.blend`, `balloon-duck-review.png`, `balloon-duck.glb`
- Goose source / portrait / runtime GLB: `../../public/assets/animals/balloon-goose.blend`, `balloon-goose-review.png`, `balloon-goose.glb`

Run from the repository root:

```powershell
blender --background --factory-startup --python art/blender/balloon_friends.py
```

By default, the deterministic script regenerates duck and goose only. It creates a separate Blender scene, editable `.blend`, 1200 × 1000 review portrait, and selected-rig GLB for each requested animal; it clears only temporary in-memory scenes. Name animals after `--` to regenerate them explicitly (for example `-- sheep cow chicken duck goose`); sheep remains excluded by default. Each GLB includes looping `WALK` and `IDLE` NLA clips and faces local +X (Blender Z-up before glTF conversion).

The sheep's vanilla balloon fleece is individually curled, with an apricot face, rose inset ears, and brass bell. The cow has an ivory balloon body with blackberry spots, rose muzzle, little cream horns, and berry collar; its refreshed articulated legs blend into the body. The chicken has a golden balloon body, vanilla bib, scalloped coral comb, tangerine beak, flapping feathered wings and splayed orange feet. The duck is a golden mallard with emerald head, chestnut breast, teal wing flashes and splayed orange webbed feet. The goose has a taller ivory silhouette, curved neck, pearl-grey feathered wings, orange bill and broad webbed feet. Review each portrait, open its `.blend` to inspect the rig/materials, then check live Three.js rendering and animation in the garden.

The runtime uses a single glossy red balloon material as the **wild carnival mask** for all six species. Every model preserves its standard GLB materials; call `animal.setAppearance('standard')` on capture to restore its authored palette (`'wild'` reapplies the full-red mask). This reversible switch is available now; the red-to-color capture transition will be animated later.

## Iteration quality gate

- Review front and three-quarter silhouette, facial expression, leg/ear/tail attachment, balloon sheen, shadow grounding, and hoof separation.
- Inspect the actual exported GLB: dimensions, facing, material appearance, clip names/durations, and loop quality. Do not rely only on Blender's viewport.
- View each animal in the intended Three.js camera and lighting. Blender render quality is a reference, not a claim that the runtime matches it.
- Keep model changes data/script driven and reproducible. Re-export the `.blend`, PNG and `.glb` together.
